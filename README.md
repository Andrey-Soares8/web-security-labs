## 🛠 Skills Demonstradas

- SQL Injection (Union-based, Error-based, Blind)
- Blind SQL Injection (Conditional Response e Time-based)
- Authentication Bypass
- Database Enumeration e Extração de Dados
- Metodologia de Exploração Web
- Uso avançado do Burp Suite (Repeater, Intruder, Proxy)
